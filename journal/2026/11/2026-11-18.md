# Day 15 · 2026-11-18 · Git worktrees

_Category: Git · Source: gemini_

Today I learned about Git worktrees, a feature that has completely transformed my multi-tasking workflow. Previously, if I was deep into a complex feature branch and a critical bug report came in, I would reluctantly `git stash` my changes, switch branches, fix the bug, and then restore my state—often risking merge conflicts or lost progress.

With `git worktree`, I can keep my main development environment intact while checking out a second branch in a completely separate directory. Both directories share the same repository metadata, so they stay perfectly in sync. When I need to address a hotfix, I simply navigate to a new folder and start working immediately without disturbing my current progress.

```bash
git worktree add ../hotfix-branch main
```

Once the hotfix is merged and pushed, I just run `git worktree remove ../hotfix-branch` to clean up the directory. It is an incredibly efficient way to manage context switching without the overhead of stashing or juggling multiple local clones.
