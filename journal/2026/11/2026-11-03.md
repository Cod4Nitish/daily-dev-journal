# Day 1 · 2026-11-03 · FastAPI dependency injection

_Category: FastAPI · Source: offline_

Today I revisited **FastAPI dependency injection** (FastAPI).

- `Depends()` lets FastAPI resolve and cache a dependency once per request.
- Dependencies with `yield` run teardown code after the response is sent, which is ideal for DB sessions.
- Sub-dependencies compose, so auth can depend on a DB session that depends on settings.

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

Takeaway: `Depends()` lets FastAPI resolve and cache a dependency once per request.
