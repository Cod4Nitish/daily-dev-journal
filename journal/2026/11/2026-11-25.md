# Day 22 · 2026-11-25 · Security basics: password hashing

_Category: Security · Source: offline_

Today I revisited **Security basics: password hashing** (Security).

- Never store plain or fast-hashed (MD5/SHA) passwords; use bcrypt, scrypt or Argon2.
- These algorithms are deliberately slow and salted per password.
- Compare secrets with constant-time functions to avoid timing leaks.

```python
import hmac
hmac.compare_digest(given_token, expected_token)
```

Takeaway: Never store plain or fast-hashed (MD5/SHA) passwords; use bcrypt, scrypt or Argon2.
