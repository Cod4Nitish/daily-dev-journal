# Day 21 · 2026-11-24 · Kotlin coroutines and Flow

_Category: Android · Source: offline_

Today I revisited **Kotlin coroutines and Flow** (Android).

- `viewModelScope` cancels coroutines automatically when the ViewModel clears.
- `StateFlow` always has a value and suits UI state.
- `collectAsStateWithLifecycle` stops collecting when the UI is in the background.

```kotlin
val ui: StateFlow<UiState> = repo.items
    .map { UiState(it) }
    .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), UiState())
```

Takeaway: `viewModelScope` cancels coroutines automatically when the ViewModel clears.
