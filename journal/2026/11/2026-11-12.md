# Day 9 · 2026-11-12 · Agent loops and stop conditions

_Category: AI/Agents · Source: offline_

Today I revisited **Agent loops and stop conditions** (AI/Agents).

- Every agent loop needs a hard iteration cap, not just a 'done' signal.
- Feeding errors back as observations lets the model self-correct.
- Logging each step's input and output makes agent bugs debuggable.

```python
for step in range(MAX_STEPS):
    action = llm(history)
    if action.done:
        break
    history.append(run(action))
```

Takeaway: Every agent loop needs a hard iteration cap, not just a 'done' signal.
