# Day 20 · 2026-11-23 · Compose side effects

_Category: Android · Source: offline_

Today I revisited **Compose side effects** (Android).

- `LaunchedEffect(key)` runs a coroutine tied to composition and restarts when the key changes.
- `DisposableEffect` is for register/unregister pairs like listeners.
- `rememberCoroutineScope` launches coroutines from event handlers.

```kotlin
LaunchedEffect(userId) {
    user = repo.load(userId)
}
```

Takeaway: `LaunchedEffect(key)` runs a coroutine tied to composition and restarts when the key changes.
