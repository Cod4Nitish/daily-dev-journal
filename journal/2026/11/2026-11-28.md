# Day 25 · 2026-11-28 · DSA pattern: sliding window

_Category: DSA · Source: offline_

Today I revisited **DSA pattern: sliding window** (DSA).

- Sliding window turns many O(n^2) substring problems into O(n).
- Expand the right edge, shrink the left while the window is invalid.
- A hashmap of counts tracks window contents.

```python
def longest_unique(s):
    seen, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if seen.get(ch, -1) >= left:
            left = seen[ch] + 1
        seen[ch] = right
        best = max(best, right - left + 1)
    return best
```

Takeaway: Sliding window turns many O(n^2) substring problems into O(n).
